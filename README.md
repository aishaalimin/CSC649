# Word and Character Counter

**Student ID:** 2024800846
**Course:** CSC649

## Description
A simple Python program that reads one sentence and reports how many words
and characters (including spaces) it contains. Empty input is handled with
a message.

## Running the program
```
python main.py
```
Requires Python 3.12. The project uses a virtual environment (`.venv`).

## Test results

**Test 1: normal sentence**
```
Enter a sentence: I love data science
Word count: 4
Character count (including spaces): 19
```

**Test 2: empty input**
```
Enter a sentence:
You did not enter a sentence.
```

**Test 3: extra spaces**
```
Enter a sentence:   hello    world  
Word count: 2
Character count (including spaces): 18
```

## Limitation
The program only processes one sentence per run. To count another
sentence, it must be run again."# CSC649"
